# Synthesis Notes

This repository is a unified, fresh implementation that combines:

- Continuity Core (C2): Event Log + multi-store memory + expected-utility context composer + credit assignment.
- Manifold Resonance Architecture (MRA): dissonance detection and conceptual void discovery with targeted inquiries.
- Biomimetic learning: nested learning, recall-gated consolidation, and strategic forgetting.

Design highlights:
- The Event Log is the canonical record; all other stores are derived views.
- Memory consolidation is gated by recall strength and adjusted via feedback.
- MRA runs as a background auditor, surfacing contradictions and gaps.

MVP MCP tools are intentionally minimal so client models can "plug into pilot mode" and access:
- event logging
- context composition
- introspection (stress/voids)
